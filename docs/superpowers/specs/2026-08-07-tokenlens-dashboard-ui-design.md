# TokenLens 现有看板 UI 轻量换肤

- 日期: 2026-08-07
- 状态: 已获用户批准
- 范围: 仅前端展示层；不改后端、轮询、数据源

## 目标

在保持现有数据流的前提下，把用量看板整理成「浅色工具台」风格：信息去重、层次清晰、数字可读，去掉默认紫调与重复列表。

## 非目标

- 不接入个人版 Credits 5 小时 / 7 天限额看板
- 不改 `UsageProvider` / CLI 解析 / API 契约（字段可继续沿用）
- 不优先做深色模式
- 不做侧栏、筛选、多页导航

## 视觉系统

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F4F5F7` | 页面底 |
| `--surface` | `#FFFFFF` | 卡片/表区域 |
| `--text` | `#5C6370` | 次要文案 |
| `--text-h` | `#1A1D26` | 标题与主数字 |
| `--border` | `#E2E5EB` | 细边框 |
| `--accent` | `#2F5BFF` | 强调（进度条、图表、标签） |
| `--accent-soft` | `rgba(47, 91, 255, 0.08)` | 标签底、面积填充 |

- 字体：标题/正文 `IBM Plex Sans`；数字与模型 ID `JetBrains Mono`（Google Fonts）
- 圆角：卡片 `8px`；避免大胶囊 pill
- 阴影：极轻（可选单层），不以多层阴影堆层次

## 页面结构

单页，自上而下四段：

1. **顶栏**
   - 左侧品牌名 `TokenLens`（产品级标题，不压过的副文案）
   - 右侧状态：数据源标签（`CLI` / `Mock`）+ 更新时间或错误提示
2. **KPI 三卡**
   - 当月账单（货币）
   - 可用余额（货币）
   - 模型用量（tokens，千分位）
3. **趋势**
   - 区块标题：「近 7 日用量」
   - ECharts 折线 + 浅面积；Y 轴 `tokens`；配色跟 `--accent`
4. **模型用量表（唯一明细）**
   - 删除右侧 `ModelList`（与消费表重复）
   - 列：模型 | 用量 | 占比（百分比 + 行内进度条）
   - 若全部 `cost === 0`：不展示金额列；表下脚注「套餐抵扣，按量金额为 0」
   - 若存在非零金额：保留金额列

## 交互与状态

- 轮询间隔与 store 逻辑不变
- 无数据：KPI 不渲染或骨架保持现有「无 payload 则空」行为即可；表区显示「暂无模型用量」
- 错误：状态栏红色/告警文案，保留上次成功数据（现有 store 行为）

## 验收标准

1. 打开看板为浅灰底 + 白卡片 + 钢蓝强调，无紫色主题残留
2. 页面仅一处模型明细表，无右侧重复列表
3. 个人版全 0 金额时不出现误导性金额列，有脚注说明
4. KPI、趋势、表在桌面与 `<768px` 单列下均可读
5. 数据源仍显示 CLI/Mock，刷新时间可见

## 实现约束

- 只改 `frontend/` 展示相关文件
- 不新增依赖（除已有 echarts/zustand/react）；字体用 CDN link，不 npm 装字体包
- 保持中文文案
